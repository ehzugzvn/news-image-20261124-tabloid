## How it works

`render.py` (PIL, run locally) draws `entry.png` at 1024×1024 — a vector-style illustration drawn entirely in code, with no borrowed images. `main.py` is stdlib-only and simply copies the pre-rendered `entry.png` to `MAKEFUN_OUTPUT_DIR/entry.png`; nothing is rendered at runtime.
