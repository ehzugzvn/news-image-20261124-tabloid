Enter the bounty: https://make.fun/bounty/news-image-20261124

## How it works

`render.py` (PIL, run locally) draws `entry.png` (1024×1024, vector-style
illustration drawn entirely in code — no borrowed images). `main.py` is
stdlib-only and simply copies the pre-rendered `entry.png` to
`MAKEFUN_OUTPUT_DIR/entry.png`; nothing is rendered at runtime.

## Facts

All facts verified from the Daily Summary Of final edition, 24 Nov 2026
(30 stories, 64 sources) with cross-checks. Verification tags on the page:
CONFIRMED = 2+ outlets or official record · OFFICIAL = on the record ·
REPORTED = one outlet · CLAIM = one side's account.
